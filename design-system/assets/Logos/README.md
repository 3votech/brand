The 3VOtech logo in three arrangements and five versions each. Every file is an SVG with a transparent ground, and TECH is outlined artwork, so no font is needed to open them.

- `3votech-horizontal-*`: the default logo, the mark beside TECH at two-thirds its height.
- `3votech-stacked-*`: TECH under the mark, tracked to the mark's width, for square spaces.
- `3votech-mark-*`: the mark alone, for icons, avatars and anything under 120px wide.

| Version | Inks | Ground |
|---|---|---|
| `-color` | Ǝ #2459F5, V #7A3CF0, O #0891B2, TECH #0D1530 | white or a light ground |
| `-color-dark` | Ǝ #5C8DFF, V #A685FF, O #22D3EE, TECH #EAF0FF; the V and O add like light where they cross | navy (#0A1230, #131C42 or #0D1530) only |
| `-navy` | one ink, #0D1530, with a knockout gap where the V crosses the O | light grounds, single-ink printing |
| `-white` | one ink, #FFFFFF, same knockout gap | dark grounds and photos, shirts, hats, decals |
| `-black` | one ink, #000000, same knockout gap | printing on paper: forms, receipts, stamps, black-and-white printers |

The `-white` files are white on transparent, so they look empty on a white preview. They are not broken.
